# AWS S3 Static Website Hosting Demo

This project demonstrates my hands-on experience with Amazon S3 Static Website Hosting.

## Project Overview
I created an Amazon S3 bucket, enabled Static Website Hosting, configured public access, and deployed a simple HTML webpage.

## Technologies Used
- Amazon S3
- HTML

## Features
- Created an S3 bucket
- Uploaded website files
- Enabled Static Website Hosting
- Configured bucket policy
- Deployed a public website
